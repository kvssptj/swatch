# Improve a weak interface

## Purpose

Learn whether the model can diagnose design problems instead of copying the source.

## What you need

- One interface with clear usability or visual problems.
- A short description of the product and user.

## Prompt

> Improve this interface. Identify the most important problems first. Then redesign the screen. Keep useful product behavior and remove unnecessary parts.

## What to observe

- Does the model find the important problems?
- Does it set clear priorities?
- Does the redesign solve the stated problems?
- Does it add unnecessary features or decoration?

## What to keep

- Keep the source, context, prompt, critique, redesign, model version, date, and your notes.
