# Describe a detailed image

## Purpose

Learn what the model sees, misses, and invents in a dense image.

## What you need

- One image with many objects, people, text, or spatial relationships.

## Prompt

> Describe everything relevant in this image. Separate direct observations from uncertain interpretations. Explain the location of important items.

## What to observe

- Which small details does the model notice?
- Does it describe spatial relationships correctly?
- Does it read visible text correctly?
- Does it state uncertainty when the image is unclear?
