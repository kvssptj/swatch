# Recreate an image

## Purpose

Learn how the model converts an image into language and then into a new image.

## What you need

- Photo 02 from the photography kit.
- An image generation tool or model.

## Use the supplied photographs

[Preview the photographs and download the inputs](../photography-kit.md). Photography by Pavan.

Attach Photo 02 in a fresh chat, then paste only the prompt below. Use the same files in every comparable run. Do not supply the reviewer guide or page captions.

Use an image-capable workflow. Record the generator and whether it receives the reference image; text-only and reference-assisted generation are separate conditions. A description without a generated image is a partial run.

## Prompt

> Use the attached image as the reference for a two-stage recreation exercise.
>
> First, write a self-contained image-generation prompt that captures the composition, framing, viewpoint, main subjects, relative positions and scale, color palette, lighting, materials, background, and visual style. Describe any legible text and its placement. Distinguish essential features from incidental details, and avoid inventing details that the reference does not resolve.
>
> Then use that written prompt to generate one image with a similar aspect ratio. If the tool permits, generate from the description alone so the result tests the translation from image to language and back. State whether the reference image was also supplied to the generation tool.
>
> Return the exact prompt, the generated image, and a brief comparison identifying the most consequential matches and departures. If generation is unavailable, return the prompt and state that limitation.

## What to observe

- Does the description capture the main composition?
- Which details survive the full process?
- Which details change or disappear?
- Does the result keep the reference mood and visual hierarchy?
