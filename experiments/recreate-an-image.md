# Recreate an image

## Purpose

Learn how the model converts an image into language and then into a new image.

## What you need

- One reference image.
- An image generation tool or model.

## Prompt

> Describe this image for a person who must recreate it. Include composition, objects, colors, light, materials, and style. Then use your description to generate a similar image.

## What to observe

- Does the description capture the main composition?
- Which details survive the full process?
- Which details change or disappear?
- Does the result keep the reference mood and visual hierarchy?

## What to keep

- Keep the reference, description, generated image, prompts, model versions, date, and your notes.
