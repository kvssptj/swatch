# Complete a task with tools

## Purpose

Learn how the model plans and completes a task that needs several tools.

## What you need

- A clear outcome that needs research, comparison, and an artifact.
- Access to the necessary tools.

## Prompt

> Find suitable options for this request. Compare the options against the stated needs. Then create the requested artifact. Check your work before you finish.

## What to observe

- Does the model make a useful plan?
- Does it select suitable tools?
- Does it verify results before it acts?
- Can it recover when a tool fails?

## What to keep

- Keep the request, tool record, artifact, model version, date, and your notes.
