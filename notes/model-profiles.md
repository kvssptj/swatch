# Model profiles

A model profile summarizes behavior that appears in more than one run.

## Use evidence

Link each observation to the runs that support it. State when the evidence is limited or mixed.

## Describe behavior

Write what the model does. Do not replace the description with a score.

Useful observations include:

- Notices small visual details but sometimes invents text.
- Makes strong layout decisions with little direction.
- Asks useful questions before it starts unclear work.
- Finds relevant sources but writes conclusions that are too certain.

## Keep change visible

Create a new entry when the model version changes. Do not replace the old profile.
