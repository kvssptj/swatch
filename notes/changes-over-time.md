# Changes over time

Run the same experiment with different generations of one model family.

Keep the prompt, inputs, and observation guide equal. Record all changes that are necessary because of tool or format limits.

Place the oldest run first. Show the artifacts at a useful size.

Describe what changed. Note new strengths, lost strengths, repeated errors, and different behavior.
